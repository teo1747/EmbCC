# src/cpp

Preprocessor — ../../docs/ARCHITECTURE.md §2 and §5.

Two parts, both live:

- **predef.c** — the predefined-macro table, generated by
  ../../tools/gen-predef.sh from `x86_64-elf-gcc -dM -E`. Never edited by hand;
  regenerating it is the only way it may change (§5 explains why the complete
  LP64 set is mandatory rather than nice-to-have).
- **cpp.c** — the preprocessor proper: `#include` (quote and angle search paths,
  `-I`/`-isystem`, `#include_next`), object- and function-like `#define` with
  `#`/`##`, `#undef`, the full conditional family (`#if`/`#ifdef`/`#elif`/
  `#else`/`#endif` with a constant-expression evaluator and `defined`),
  `#line`, `#error`, `#pragma once`, and `__FILE__`/`__LINE__`/`__COUNTER__`.

The bar it is held to is §5's: it digests **real newlib headers**, so
`#include <stdio.h>` compiles, links and runs. It also digests the EmbLinkOS
kernel's own headers — the whole kernel preprocesses through this file.

`embcc -E` runs the preprocessor alone and writes the expanded source.
